# English Mastery — Master English, Step by Step.

منصة لتعلّم الإنجليزية من A0 إلى C1: Next.js 14 + Tailwind + Supabase. واجهة عربية RTL، وضع ليلي/نهاري، وتعمل على الهاتف.

## حالة المشروع بصراحة

| الجزء | الحالة |
|---|---|
| قاعدة البيانات (20+ جدولاً، RLS، دوال التصحيح والتقدم) | **طُبّقت على مشروع Supabase واختُبرت فعلياً** (انظر أدناه) |
| المنهج: 6 مستويات، 12 وحدة، 30 درساً، 363 سؤالاً، 48 كلمة، 6 نصوص | **مُدخل في قاعدة البيانات** |
| كود الموقع (الصفحات والمكونات ومسارات API) | **مكتوب ولم يُشغَّل**: لم يُنفَّذ `npm install` ولا `npm run build`، لأن بيئة الكتابة بلا شبكة |
| ميزات الذكاء الاصطناعي | تحتاج `AI_API_KEY` من جهتك، ولم تُجرَّب أبداً مع النموذج |

**اختُبر على قاعدة البيانات (داخل عمليات تُلغى تلقائياً):** إنشاء الملف الشخصي تلقائياً، منع الترقية إلى مدير، منع تعديل النقاط/المستوى مباشرة،
إخفاء مفاتيح الإجابات عن المتصفح، التصحيح من الخادم، النقاط مرة واحدة فقط لكل نجاح، قفل المستويات، فتح A1 بعد اجتياز اختبار A0 النهائي،
اشتراط إكمال كل الدروس قبل الاختبار النهائي، اختبار تحديد المستوى، المراجعة المتباعدة، التحديات (مرة واحدة)، الشارات، عزل بيانات المستخدمين، صلاحيات المدير.

**لم يُختبر:** كل كود الواجهة (فحصت فقط الصياغة والأنواع بشكل جزئي دون الحزم). توقّع أخطاء بناء أو تشغيل عند أول تشغيل، وأرسلها لإصلاحها.

## التشغيل

1. ثبّت Node.js 18.18 أو أحدث.
2. في Supabase: **Authentication > URL Configuration**: Site URL = `http://localhost:3000` وأضف Redirect URL: `http://localhost:3000/auth/callback`.
3. ملف `.env.local` موجود (فيه المفتاح العام فقط). لتفعيل الذكاء الاصطناعي ضع `AI_API_KEY`.
4. ```bash
   npm install
   npm run build     # يكشف أخطاء الأنواع والـ lint
   npm run dev
   ```
5. افتح http://localhost:3000

> التأكيد بالبريد: افتراضياً مفعّل. للتجربة السريعة عطّله من **Authentication > Providers > Email > Confirm email**.

### أول مدير
سجّل حساباً ثم نفّذ في SQL Editor:
```sql
update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'your@email.com');
```

## قاعدة البيانات
- `supabase/migrations/0001_init.sql` و`0002_harden.sql` موجودان هنا.
- باقي التغييرات (المنهج، دوال التصحيح، الشارات، قفل المستويات…) نُفّذت على مشروعك عبر موصل Supabase ولا توجد كملفات في هذا الأرشيف.
  لاستخراجها كملفات: `supabase link --project-ref dqodomlmsxkbaxngpxub` ثم `supabase db pull`.
- حماية التقدم: لا يستطيع المتصفح كتابة النقاط أو النتائج أو المستوى مباشرة؛ كل ذلك عبر دوال `submit_quiz_attempt` و`review_word` و`claim_challenge` و`track_time` داخل القاعدة.
- مفاتيح الإجابات في `questions.answer_key` لا تُقرأ من المتصفح (صلاحيات أعمدة)؛ المدير يقرؤها عبر `admin_get_questions`.

## الخدمات الخارجية
| الخدمة | الاستخدام | ملاحظات |
|---|---|---|
| Supabase | قاعدة البيانات والحسابات والتخزين | الخطة المجانية لها حدود؛ راجع صفحة الأسعار. خدمة البريد المدمجة للتجربة فقط، واربط SMTP للإنتاج. |
| نموذج ذكاء اصطناعي (`AI_API_KEY`) | المدرّس، تقييم الكتابة، PDF إلى اختبار، الترجمة | **مدفوع حسب الاستهلاك**. الحد اليومي لكل مستخدم 40 طلباً (قابل للتغيير من إعدادات المدير: `ai_daily_limit`). |
| صوت المتصفح (Web Speech API) | النطق والاستماع والتعرف على الكلام | **مجاني بلا مفاتيح** لكن الجودة والأصوات تختلف بحسب الجهاز والمتصفح؛ تمييز الكلمة أثناء القراءة لا يعمل في كل المتصفحات؛ التعرف على الكلام يعتمد على المتصفح (Chrome/Edge/Safari). مقارنة النطق تعتمد على ما فهمه المتصفح وليست تحليلاً صوتياً دقيقاً. |

### PDF إلى اختبار
- الرفع من المتصفح إلى حاوية `pdfs` الخاصة (مجلد لكل مستخدم، حد 20MB، PDF فقط، وفحص `%PDF-` على الخادم).
- استخراج النص وقراءة الملفات الممسوحة ضوئياً (OCR) يتمّان بواسطة النموذج نفسه عند قراءة الملف، لذلك لا توجد خدمة OCR منفصلة. هذا يعني: التكلفة تزيد بعدد صفحات الملف، وللنموذج حدّ على عدد الصفحات (يُعرض خطأ واضح عند تجاوزه).
- الأسئلة مقيّدة بمحتوى الملف مع الصفحة والمقتطف، وإن لم تكفِ المادة يُنشأ عدد أقل بدل الاختلاق.
- على Vercel: التوليد قد يستغرق دقيقة أو أكثر؛ تأكد أن خطتك تسمح بمدة تنفيذ كافية (الإعداد `maxDuration = 300`).

## ما يجب معرفته
- المنهج الحالي **بداية**: 30 درساً تغطي كل مواضيع القواعد العشرين، لكن أعمق بكثير مما ستحتاجه منصة كاملة. أضف المزيد من لوحة المدير (المحتوى والأسئلة) بلا تعديل كود.
- أيام التتابع تُحسب بتوقيت UTC.
- ألعاب المفردات والقواعد وتمارين الدرس تُصحَّح في المتصفح للتدريب (بلا نقاط)؛ النقاط فقط من الاختبارات الرسمية المصحَّحة في القاعدة.
- لا يوجد اختبار نطق قائم بذاته للمستوى؛ التدريب على النطق متاح داخل الدروس.
